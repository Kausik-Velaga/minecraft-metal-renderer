# Minecraft Metal 0.2.0 — experimental release for Minecraft 26.3

Run Minecraft Java 26.3 through Apple's Metal graphics API on an Apple Silicon Mac. This is the first downloadable GitHub prerelease, intended for testing.

**AI disclosure:** the custom implementation, tests, and project documentation were completely AI-generated using Codex, with human direction and testing. Third-party components retain their original authorship. Screenshots and logs are actual game captures.

## Install

1. Use an Apple Silicon Mac with macOS 14+ and ARM64 Java 25+.
2. Set up a separate Minecraft **26.3** profile with **Fabric Loader 0.19.5** (minimum 0.19.3).
3. Download **`minecraft-metal-renderer-0.2.0.jar`** from the assets below and place it in that profile's `mods` folder. Do not use the **Source code** archives.
4. Launch the Fabric profile. Metal activates automatically.

Fabric API is not required. The Metal library is included; no compiling or developer tools are needed. See the [detailed installation guide](https://github.com/Kausik-Velaga/minecraft-metal-renderer/blob/v0.2.0/docs/installation.md).

## In this version

- Support for Minecraft 26.3's rendering interfaces and native Metal presentation.
- Rendering of terrain, water, glass, entities, particles, inventory, and lighting in the tested scenes.
- Improved Transparency support, including overlapping glass and boat water masks.
- Resource reload, resizing, and fullscreen transitions exercised by the validation scenarios.

The earlier 0.1.0 development build targeted Minecraft 26.2. Remove it before installing this version.

## Tested scope and limitations

Tested on an Apple M3 Pro running macOS 26.5.2. The clean official-launcher test used ARM64 Java 25.0.1, Fabric Loader 0.19.5, and this mod without Fabric API. The user reported normal rendering during the requested visual walkthrough. Automated GPU and gameplay checks are recorded separately in the [validation report](https://github.com/Kausik-Velaga/minecraft-metal-renderer/blob/v0.2.0/docs/validation.md).

This is experimental software with limited hardware and gameplay coverage. Intel Macs, Windows, and Linux are unsupported. Sodium, Iris, shader packs, other rendering mods, and third-party resource packs are unverified. Start with this mod alone. No comparative FPS improvement has been established.
