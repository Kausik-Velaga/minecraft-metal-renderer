Minecraft Metal suite — experimental, client-only

Requires Minecraft Java 26.3, Fabric Loader 0.19.5 (minimum 0.19.3),
ARM64 Java 25+, macOS 14+, and an Apple Silicon Mac.
Fabric API, Iris and Sodium are not required. Intel Macs, Windows and Linux
are unsupported. Other rendering replacements have not been validated.

Included:
  Minecraft Metal 0.2.2 — native graphics backend
  Minecraft Shader Loader 0.1.3 — pack loading and rendering
  Minecraft Scene Optimizer 0.1.0 — scene preparation
  Solstice 0.1.0 — lighter lighting, water, shadows and bloom

INSTALL
1. Close Minecraft. Create a separate Fabric 26.3 profile with its own game
   directory.
2. Extract the outer suite ZIP once. Keep the three JARs and Solstice ZIP
   intact. Do not place the suite ZIP itself in mods.
3. Copy the three files from mods into the profile's mods folder. Remove
   older versions of these three mods; keep one copy of each.
4. Copy Solstice-0.1.0.zip from shaderpacks into the profile's shaderpacks folder.
5. For a fresh profile, copy config/minecraft-shader-loader.properties into
   the profile's config folder. On an existing profile, edit the existing
   file instead of overwriting settings: set pack=Solstice-0.1.0.zip and
   profile=BALANCED. Remove old option.* settings that the new pack lacks.
6. Launch the Fabric profile. Metal and Solstice activate automatically.

Change the pack and profile settings in the configuration file to select a
different shader pack, then restart Minecraft. There is no shader selection screen yet.
To use ordinary rendering, leave pack= empty or remove the shader loader.
The scene optimizer is optional. Both companions require Minecraft Metal.

PERFORMANCE
PERFORMANCE.md documents optional tuning used for the published measurements.
The ZIP does not alter launcher JVM arguments or system environment settings.
Performance depends on the scene, settings and device; frame-time spikes remain.
