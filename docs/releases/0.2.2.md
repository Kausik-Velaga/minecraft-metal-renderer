# Minecraft Metal 0.2.2 — three mods and two original shader packs

Experimental release for **Minecraft Java 26.3 on Apple Silicon Macs**.

| Component | Version | Purpose |
| --- | --- | --- |
| Minecraft Metal | 0.2.2 | Native Metal graphics backend |
| Minecraft Shader Loader | 0.1.3 | Shader-pack compatibility, scene passes and materials |
| Minecraft Scene Optimizer | 0.1.0 | Scene selection and retained terrain metadata |
| Canopy | 0.2.0 | Material highlights, biome atmosphere, block clouds and water reflections |
| Solstice | 0.1.0 | Lighter lighting, shadows, water and bloom |

Download **minecraft-metal-suite-0.2.2.zip** for all three mods, both original
shader packs, a Canopy selection configuration, licenses and installation
instructions. Individual JARs and pack ZIPs are also available below.
**BSL is not included.** No Minecraft files, third-party shader code, reference
artwork, profiler or world saves are bundled.

## Install or update

Use Fabric Loader **0.19.5** (minimum 0.19.3), **ARM64 Java 25+**, and **macOS 14+**.
Fabric API is not required. Intel Macs, Windows and Linux are unsupported.

1. Close Minecraft and use a separate Fabric 26.3 game directory for testing.
2. Extract the suite ZIP once. Copy its three intact JARs to `mods`, removing
   older versions of those mods.
3. Copy the two intact shader ZIPs to `shaderpacks`.
4. On a fresh profile, copy the supplied configuration into `config`. For an
   existing profile, edit `config/minecraft-shader-loader.properties` to set
   `pack=Canopy-0.2.0.zip` and `profile=BALANCED`; remove incompatible old options.
5. Launch Minecraft. To switch looks, set `pack=Solstice-0.1.0.zip` and restart.

The renderer works alone. Both companion mods require renderer 0.2.2; they
can be installed independently of one another. There is no shader settings
screen yet. GitHub's automatic **Source code** archives are not installable mods.

## Changes

- Separate scene optimizer with a bounded spatial-index worker, per-view
  selection, retained section/layer metadata and optional draw-metadata caching.
- Renderer improvements for GPU resource lifetime, transient uploads, indirect
  draw handling, sampler state and pipeline resource binding; additional
  synchronization and timing diagnostics.
- Loader fixes and optimizations for shadow selection, terrain sampling,
  geometry adaptation, shader compilation, mipmaps and fullscreen passes.
- Original Solstice and Canopy packs. Canopy supplies 50 material recipes,
  including pixel-specific ore and lamp masks. The loader creates a reusable
  material atlas and supports resource-pack overrides and reload invalidation.
- Reproducible packaged benchmarks, optional external Spark profiling, GPU
  checks and gameplay validation. Profiling tools are not included in the mods.

## Validation and limitations

Release build checks cover all three modules, native GPU operations and both
packs' Metal shader variants. Both original packs also passed short launches with
all three packaged production mods and no Fabric API. Material/gallery tests cover resource reload and
overrides; gameplay checks cover leaf breaking, entities, particles, water,
resizing and dimension transitions. Testing remains limited to one M3 Pro
configuration and specific scenes.

The tuned Canopy forest run averaged **113.64 FPS at native 3456×2168** but
included a **517 ms hitch**. This is not locked 90 FPS. Some optimizations remain
opt-in: see the bundle's `PERFORMANCE.md` for the launch configuration behind
that measurement. It is not a claim about untouched runtime defaults.

Canopy's material atlas used **21.31 MiB** in the tested vanilla scene. Coverage
is partial: normal maps, separate entity atlases and nonuniform animated
material masks remain unsupported. Arbitrary shader packs, third-party
resource packs, Sodium and Iris combinations are not broadly validated.

Custom implementation, tests, shader packs and documentation are AI-generated
under human direction. Gameplay captures are actual game output. The project's
own licensable material is offered under MIT with third-party qualifications
retained. This is unofficial and is not approved by Mojang or Microsoft.
